# 输入法选择器

选择当前组内的输入法。

## 设置

### 触发键

按下配置的快捷键，在候选窗中显示当前组的输入法列表。

选字键为 `1` 至 `9` 和 `0`，也可以移动高亮后按空格或回车选择，按 `Esc` 取消。翻页、移动高亮的快捷键在 `全局配置` -> `快捷键` 设置。

选择组内非第一项输入法时，还会将其设为当前组的默认输入法。

### 当前输入上下文的触发键

同样调出输入法列表，但选择后仅更改当前输入上下文使用的输入法，不改变当前组的默认输入法。

### 切换到第...个输入法的按键

不调出列表，按下快捷键直接切换到对应输入法。快捷键列表中的第 n 项对应当前组的第 n 个输入法，英文键盘也计算在内。

示例：当前组的输入法依次为英文键盘、拼音、Rime，快捷键依次配置为 `Ctrl+Option+1`、`Ctrl+Option+2`、`Ctrl+Option+3`，则：

* `Ctrl+Option+1`：切换到英文键盘；
* `Ctrl+Option+2`：切换到拼音；
* `Ctrl+Option+3`：切换到 Rime。

调整输入法顺序或切换输入法组后，快捷键仍按当前组的顺序对应。选择组内非第一项输入法时，同样会更新当前组的默认输入法。

点击输入法菜单中的输入法也采用此切换方式，其中支持显示的快捷键会出现在对应菜单项旁。

### 局部切换到第...个输入法的按键

同样按快捷键列表的顺序直接选择输入法，但仅更改当前输入上下文使用的输入法，不改变当前组的默认输入法。

::: info
“当前输入上下文”通常对应当前输入框。若在 `全局配置` -> `行为` 中启用了 `共享输入状态`，局部选择的输入法也可能随输入状态共享到其他输入上下文。
:::
